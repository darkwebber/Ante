# "Ante" RFCs

Big changes kosam RFC (Request for Comments) raasthaam: new syntax, semantics change, type system, ownership, chaala words okesari change chese vocabulary, Edition 2 ideas.

Oka chinna word change ki RFC avasaram ledhu. [Vocabulary proposal issue](https://github.com/darkwebber/Ante/issues/new?template=vocabulary_proposal.yml) chaalu.

## Process

1. [`0000-template.md`](0000-template.md) ni `0000-mee-topic.md` ga copy cheyyandi.
2. Fill chesi PR open cheyyandi. Title: `docs(rfc): <topic>`.
3. Kanisam **14 days** discussion.
4. Maintainers decide chesthaaru: accept, postpone, or reject, reason tho.
5. Accept aithe file ki number isthaaru (`0007-…`), merge chesthaaru. Implementation separate PRs lo.
